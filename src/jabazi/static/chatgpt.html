JABBAZI GURU / PRIVATE SCANNER

“Scan everything.”
Your research, inside ChatGPT.

Connect the cloud scanner to your own custom GPT. Live odds and available model probabilities come from your server. Models remain in research mode.

1. Open your Scanner GPT

Open ChatGPT in your browser, then open or create your custom GPT and select Configure. Name it JABBAZI Scanner. Keep sharing set to Only me.

A regular conversation does not gain a tool just by renaming it. The connection belongs to the custom GPT.

Open ChatGPT

2. Connect the action

Under Actions, create an action and import this URL:

https://jabbazi-research-api.onrender.com/chatgpt/openapi.json

Choose API Key → Bearer authentication. Unlock below to copy a key restricted to scans and research results. Enter it only in the action's authentication field.

Scanner key is locked.

3. Add the GPT instructions

4. Test, then save privately

Test getScannerModelStatus first. Then type scan everything in the GPT preview and approve its scan request. It must call the real action and show a scan ID and returned results. Save with Only me, and use that GPT for your scanner conversations.

A scan uses up to 15 credits from the existing odds-provider allowance. This integration cannot place bets or publish to Discord. Changing JABBAZI_CHATGPT_TOKEN_VERSION on the server revokes the old scanner key; JABBAZI_CHATGPT_ENABLED=false disables this connection.
