## Research required behind this style of bet

1. Alternate player thresholds: fit usage and outcome distributions using snaps,
   routes, targets/carries and current availability; evaluate each offered threshold.
2. NFL touchdowns: separate team scoring volume from player scoring share, with
   red-zone/goal-line roles and injury-driven changes. First-TD is a distinct model.
3. MLB moneylines/run lines: starter, bullpen, lineup and run distribution evidence.
4. Tennis moneylines: surface-specific strength, opponent adjustment, serve/return
   performance and availability; keep tennis separate from team-sport ratings.
5. Parlays/SGPs: model dependence and compare joint fair value with the actual payout.
6. Release gates: timestamped historical prices/features, calibration on separate
   data, untouched evaluation, prospective records, CLV and complete settled returns.

The current deployed baseline models do not yet establish these capabilities.
A copied layout, long winning streak claim, or high hit rate is not validation.
